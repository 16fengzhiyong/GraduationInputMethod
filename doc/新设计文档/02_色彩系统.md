# 色彩系统设计

## 1. 色彩理念

### 1.1 设计灵感
色彩系统灵感来源于**赛博朋克美学**与**深空宇宙**的融合，营造出科技未来感的视觉氛围。

### 1.2 色彩原则
- **深色为主**：减少视觉疲劳，突出内容
- **霓虹点缀**：强调交互元素，引导视线
- **层次分明**：通过明暗对比建立信息层级
- **动态渐变**：增加视觉活力和科技感

## 4. 透明度系统

### 4.1 透明度等级

| 等级 | 值 | 用途 |
|------|-----|------|
| **完全不透明** | 1.0f | 主要文字、按键背景 |
| **高不透明** | 0.87f | 次要文字 |
| **中不透明** | 0.6f | 占位符、禁用状态 |
| **低不透明** | 0.3f | 分割线、边框 |
| **半透明** | 0.15f | 涟漪效果、阴影 |
| **微透明** | 0.08f | 毛玻璃背景 |
| **几乎透明** | 0.04f | 极淡装饰 |

## 7. 色彩对比度规范

### 7.1 WCAG 2.1 AA 标准

| 元素类型 | 最小对比度 | 推荐对比度 |
|----------|-----------|-----------|
| 正文文字 | 4.5:1 | 7:1 |
| 大文字（18px+） | 3:1 | 4.5:1 |
| 图标/图形 | 3:1 | 4.5:1 |
| 键盘按键 | 3:1 | 4.5:1 |

### 7.2 对比度检查

```kotlin
// 检查文字与背景对比度
fun checkContrast(textColor: Color, backgroundColor: Color): Boolean {
    val contrastRatio = calculateContrastRatio(textColor, backgroundColor)
    return contrastRatio >= 4.5f  // AA 标准
}

// 计算对比度
fun calculateContrastRatio(color1: Color, color2: Color): Float {
    val luminance1 = calculateLuminance(color1)
    val luminance2 = calculateLuminance(color2)
    val lighter = maxOf(luminance1, luminance2)
    val darker = minOf(luminance1, luminance2)
    return (lighter + 0.05f) / (darker + 0.05f)
}
```

## 8. 色彩使用示例

### 8.1 按键颜色应用

```kotlin
@Composable
fun KeyButton(
    label: String,
    isPressed: Boolean,
    isSelected: Boolean,
    theme: KeyboardTheme
) {
    val backgroundColor = when {
        isSelected -> theme.accentColor.copy(alpha = 0.2f)
        isPressed -> theme.keyBackgroundPressed
        else -> theme.keyBackground
    }
    
    val textColor = when {
        isSelected -> theme.accentColor
        isPressed -> theme.textColor.copy(alpha = 0.8f)
        else -> theme.textColor
    }
    
    Box(
        modifier = Modifier
            .background(
                brush = backgroundColor,
                shape = RoundedCornerShape(16.dp)
            )
            .border(
                width = 1.dp,
                color = theme.accentColor.copy(alpha = 0.3f),
                shape = RoundedCornerShape(16.dp)
            )
    ) {
        Text(
            text = label,
            color = textColor,
            style = MaterialTheme.typography.titleLarge
        )
    }
}
```

### 8.2 候选栏颜色应用

```kotlin
@Composable
fun CandidateBar(
    candidates: List<String>,
    selectedIndex: Int,
    theme: KeyboardTheme
) {
    LazyRow(
        modifier = Modifier
            .fillMaxWidth()
            .background(
                color = Color.White.copy(alpha = 0.08f),
                shape = RoundedCornerShape(16.dp)
            )
            .blur(20.dp)
    ) {
        itemsIndexed(candidates) { index, candidate ->
            val backgroundColor = if (index == selectedIndex) {
                theme.accentColor.copy(alpha = 0.2f)
            } else {
                Color.Transparent
            }
            
            val textColor = if (index == selectedIndex) {
                theme.accentColor
            } else {
                theme.textColor
            }
            
            Text(
                text = candidate,
                color = textColor,
                modifier = Modifier
                    .background(
                        color = backgroundColor,
                        shape = RoundedCornerShape(12.dp)
                    )
                    .padding(horizontal = 16.dp, vertical = 8.dp)
            )
        }
    }
}
```
