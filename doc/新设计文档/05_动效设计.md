# 动效设计规范

## 1. 设计理念

### 1.1 核心目标
通过**流畅、自然、有意义**的动效，增强用户体验的沉浸感和科技感，让每一次交互都充满生命力。

### 1.2 设计原则
- **目的性**：动效服务于功能，不是装饰
- **流畅性**：60fps 流畅动画，无卡顿
- **一致性**：统一的动效语言和时长
- **可访问性**：支持动效减弱选项

## 2. 动效基础

### 2.1 时长规范

| 动效类型 | 时长 | 缓动函数 | 用途 |
|----------|------|----------|------|
| **微动效** | 100ms | Linear | 按键按压、涟漪 |
| **快速动效** | 200ms | FastOutSlowIn | 状态切换、颜色变化 |
| **标准动效** | 300ms | FastOutSlowIn | 面板展开、布局切换 |
| **慢速动效** | 500ms | FastOutSlowIn | 复杂转场、粒子效果 |
| **弹性动效** | 300-500ms | Spring | 按键回弹、列表滚动 |

```kotlin
fun KeyPressAnimation(
    isPressed: Boolean,
    content: @Composable () -> Unit
) {
```

### 3.2 涟漪效果

```kotlin
@Composable
fun RippleEffect(
    color: Color,
    center: Offset,
    maxRadius: Float,
    onStart: () -> Unit,
    onEnd: () -> Unit
) {
    var radius by remember { mutableStateOf(0f) }
    var alpha by remember { mutableStateOf(0.3f) }
    
    LaunchedEffect(Unit) {
        onStart()
        animate(
            initialValue = 0f,
            targetValue = maxRadius,
            animationSpec = tween(300)
        ) { value ->
            radius = value
            alpha = 0.3f * (1 - value / maxRadius)
        }
        onEnd()
    }
    
    Canvas(modifier = Modifier.fillMaxSize()) {
        drawCircle(
            color = color.copy(alpha = alpha),
            radius = radius,
            center = center
        )
    }
}
```

**动效参数：**
- 起始半径：0
- 终止半径：按键对角线长度
- 起始透明度：0.3
- 终止透明度：0
- 时长：300ms
- 缓动：线性

```kotlin
@Composable
fun ModeSwitchAnimation(
    currentMode: KeyboardMode,
    targetMode: KeyboardMode,
    content: @Composable (KeyboardMode) -> Unit
) {
    var transitionState by remember { mutableStateOf(0f) }
    
    LaunchedEffect(targetMode) {
        animate(
            initialValue = 0f,
            targetValue = 1f,
            animationSpec = tween(300)
        ) { value ->
            transitionState = value
        }
    }
    
    Box(modifier = Modifier.fillMaxSize()) {
        // 当前模式
        Box(
            modifier = Modifier
                .graphicsLayer {
                    translationX = -size.width * transitionState
                    alpha = 1f - transitionState
                }
        ) {
            content(currentMode)
        }
        
        // 目标模式
        Box(
            modifier = Modifier
                .graphicsLayer {
                    translationX = size.width * (1f - transitionState)
                    alpha = transitionState
                }
        ) {
            content(targetMode)
        }
    }
}
```

**动效参数：**
- 位移：从右向左滑动
- 透明度：交叉淡入淡出
- 时长：300ms

## 6. 特效动效

### 6.1 粒子效果

```kotlin
@Composable
fun ParticleEffect(
    color: Color,
    particleCount: Int = 20,
    duration: Long = 1000
) {
    val particles = remember {
        List(particleCount) {
            Particle(
                x = Random.nextFloat(),
                y = Random.nextFloat(),
                vx = (Random.nextFloat() - 0.5f) * 2f,
                vy = (Random.nextFloat() - 0.5f) * 2f,
                size = Random.nextFloat() * 4f + 2f,
                alpha = Random.nextFloat() * 0.5f + 0.5f
            )
        }
    }
    
    var animationState by remember { mutableStateOf(0f) }
    
    LaunchedEffect(Unit) {
        animate(
            initialValue = 0f,
            targetValue = 1f,
            animationSpec = tween(duration.toInt())
        ) { value ->
            animationState = value
        }
    }
    
    Canvas(modifier = Modifier.fillMaxSize()) {
        particles.forEach { particle ->
            val x = (particle.x + particle.vx * animationState) * size.width
            val y = (particle.y + particle.vy * animationState) * size.height
            val alpha = particle.alpha * (1f - animationState)
            
            drawCircle(
                color = color.copy(alpha = alpha),
                radius = particle.size,
                center = Offset(x, y)
            )
        }
    }
}

data class Particle(
    val x: Float,
    val y: Float,
    val vx: Float,
    val vy: Float,
    val size: Float,
    val alpha: Float
)
```

**动效参数：**
- 粒子数量：20
- 扩散范围：随机方向
- 衰减：透明度线性衰减
- 时长：1000ms
- 缓动：线性

### 6.2 脉冲波纹效果

```kotlin
@Composable
fun PulseRippleEffect(
    color: Color,
    maxRadius: Float = 100f,
    pulseCount: Int = 3
) {
    val infiniteTransition = rememberInfiniteTransition()
    
    val pulseAnimations = List(pulseCount) { index ->
        val delay = index * 300
        
        val radius by infiniteTransition.animateFloat(
            initialValue = 0f,
            targetValue = maxRadius,
            animationSpec = infiniteRepeatable(
                animation = tween(1000, delayMillis = delay),
                repeatMode = RepeatMode.Restart
            )
        )
        
        val alpha by infiniteTransition.animateFloat(
            initialValue = 0.5f,
            targetValue = 0f,
            animationSpec = infiniteRepeatable(
                animation = tween(1000, delayMillis = delay),
                repeatMode = RepeatMode.Restart
            )
        )
        
        Pair(radius, alpha)
    }
    
    Canvas(modifier = Modifier.fillMaxSize()) {
        pulseAnimations.forEach { (radius, alpha) ->
            drawCircle(
                color = color.copy(alpha = alpha),
                radius = radius,
                style = Stroke(width = 2.dp.toPx())
            )
        }
    }
}
```

**动效参数：**
- 脉冲数量：3
- 延迟间隔：300ms
- 最大半径：100dp
- 透明度：0.5 → 0
- 时长：1000ms（每个脉冲）
- 循环：无限循环
