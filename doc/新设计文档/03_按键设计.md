# 按键设计规范

## 1. 设计理念

### 1.1 核心目标
打造具有**真实物理质感**的虚拟按键，通过凸起效果、光影变化和触觉反馈，让用户感受到"按下去"的真实体验。

### 1.2 设计原则
- **立体感**：通过阴影和渐变营造3D凸起效果
- **真实感**：模拟真实按键的材质和光影
- **反馈感**：按压时的视觉和触觉反馈
- **一致性**：所有按键保持统一的视觉语言

## 2. 按键类型

### 2.1 字母键（Letter Keys）

```
┌─────────────────┐
│                 │   ← 顶部高光（模拟光源）
│       Q         │   ← 字符标签
│                 │   ← 底部阴影
└─────────────────┘
```

**尺寸规范：**
- 宽度：屏幕宽度 / 10（减去间距）
- 高度：48dp
- 圆角：16dp
- 间距：5dp

### 2.2 功能键（Function Keys）

```
┌─────────────────┐
│                 │   ← 渐变背景
│       ⇧         │   ← 功能图标
│                 │   ← 霓虹边框
└─────────────────┘
```

**功能键列表：**
- Shift（⇧）
- Delete（⌫）
- Enter（↵）
- 符号切换（符）
- 语言切换（中/En）

### 2.3 特殊键（Special Keys）

```
┌───────────────────────────────────────┐
│                                       │   ← 加宽设计
│              空格键                    │   ← 渐变背景
│                                       │   ← 中间指示条
└───────────────────────────────────────┘
```

**特殊键类型：**
- 空格键（加宽）
- 搜索按钮（霓虹渐变）
- 语音按钮（脉冲动画）

## 3. 凸起效果实现

### 3.1 阴影系统

```kotlin
// 多层阴影营造立体感
fun Modifier.keyShadow(
    elevation: Dp = 4.dp,
    isPressed: Boolean = false
): Modifier = this.drawBehind {
    if (!isPressed) {
        // 第一层：基础阴影
        drawRect(
            color = Color.Black.copy(alpha = 0.3f),
            topLeft = Offset(0f, elevation.toPx()),
            size = Size(size.width, size.height),
            cornerRadius = CornerRadius(16.dp.toPx())
        )
        
        // 第二层：扩散阴影
        drawRect(
            color = Color.Black.copy(alpha = 0.15f),
            topLeft = Offset(-2.dp.toPx(), elevation.toPx() + 2.dp.toPx()),
            size = Size(size.width + 4.dp.toPx(), size.height + 4.dp.toPx()),
            cornerRadius = CornerRadius(18.dp.toPx())
        )
        
        // 第三层：彩色光晕（可选）
        drawRect(
            color = Color(0xFF00D4FF).copy(alpha = 0.1f),
            topLeft = Offset(-4.dp.toPx(), elevation.toPx() + 4.dp.toPx()),
            size = Size(size.width + 8.dp.toPx(), size.height + 8.dp.toPx()),
            cornerRadius = CornerRadius(20.dp.toPx())
        )
    }
}
```

## 4. 按键状态

### 4.1 状态定义

```kotlin
enum class KeyState {
    DEFAULT,    // 默认态
    HOVER,      // 悬停态（鼠标/手指接近）
    PRESSED,    // 按压态
    SELECTED,   // 选中态（如 Shift 开启）
    DISABLED    // 禁用态
}
```

### 4.2 状态样式

```kotlin
@Composable
fun getKeyColors(state: KeyState, theme: KeyboardTheme): KeyColors {
    return when (state) {
        KeyState.DEFAULT -> KeyColors(
            background = theme.keyBackground,
            textColor = theme.textColor,
            shadowAlpha = 0.3f,
            highlightAlpha = 0.15f,
            borderAlpha = 0.3f
        )
        
        KeyState.HOVER -> KeyColors(
            background = theme.keyBackgroundHover,
            textColor = theme.textColor,
            shadowAlpha = 0.4f,
            highlightAlpha = 0.2f,
            borderAlpha = 0.5f
        )
        
        KeyState.PRESSED -> KeyColors(
            background = theme.keyBackgroundPressed,
            textColor = theme.textColor.copy(alpha = 0.8f),
            shadowAlpha = 0.1f,  // 阴影减小
            highlightAlpha = 0.05f,  // 高光减弱
            borderAlpha = 0.6f  // 边框增强
        )
        
        KeyState.SELECTED -> KeyColors(
            background = theme.accentColor.copy(alpha = 0.2f),
            textColor = theme.accentColor,
            shadowAlpha = 0.4f,
            highlightAlpha = 0.25f,
            borderAlpha = 0.8f
        )
        
        KeyState.DISABLED -> KeyColors(
            background = theme.keyBackground.copy(alpha = 0.5f),
            textColor = theme.textColor.copy(alpha = 0.4f),
            shadowAlpha = 0.1f,
            highlightAlpha = 0.05f,
            borderAlpha = 0.1f
        )
    }
}
```

### 4.3 状态转换动画

```kotlin
@Composable
fun KeyButton(
    label: String,
    state: KeyState,
    theme: KeyboardTheme
) {
    val colors = getKeyColors(state, theme)
    
    // 动画值
    val shadowAlpha by animateFloatAsState(
        targetValue = colors.shadowAlpha,
        animationSpec = tween(durationMillis = 100)
    )
    
    val highlightAlpha by animateFloatAsState(
        targetValue = colors.highlightAlpha,
        animationSpec = tween(durationMillis = 100)
    )
    
    val scale by animateFloatAsState(
        targetValue = if (state == KeyState.PRESSED) 0.95f else 1f,
        animationSpec = spring(
            dampingRatio = Spring.DampingRatioMediumBouncy,
            stiffness = Spring.StiffnessLow
        )
    )
    
    // 按键实现
    Box(
        modifier = Modifier
            .graphicsLayer {
                scaleX = scale
                scaleY = scale
            }
            .keyShadow(
                elevation = if (state == KeyState.PRESSED) 1.dp else 4.dp,
                isPressed = state == KeyState.PRESSED
            )
            .background(
                brush = if (state == KeyState.PRESSED) {
                    theme.keyBackgroundPressed
                } else {
                    theme.keyBackground
                },
                shape = RoundedCornerShape(16.dp)
            )
            .keyHighlight(highlightAlpha)
            .neonBorder(
                color = theme.accentColor,
                alpha = colors.borderAlpha
            )
    ) {
        Text(
            text = label,
            color = colors.textColor,
            style = MaterialTheme.typography.titleLarge
        )
    }
}
```

```kotlin
fun SpaceKey(
```

## 6. 按键布局

### 6.1 标准 QWERTY 布局

```kotlin
@Composable
fun QWERTYKeyboard(
    theme: KeyboardTheme,
    onKeyPress: (Char) -> Unit
) {
    Column(
        verticalArrangement = Arrangement.spacedBy(5.dp)
    ) {
        // 第一行：Q W E R T Y U I O P
        Row(
            horizontalArrangement = Arrangement.spacedBy(5.dp)
        ) {
            "QWERTYUIOP".forEach { char ->
                KeyButton(
                    label = char.toString(),
                    modifier = Modifier.weight(1f),
                    theme = theme,
                    onClick = { onKeyPress(char) }
                )
            }
        }
        
        // 第二行：A S D F G H J K L（缩进）
        Row(
            modifier = Modifier.padding(horizontal = 15.dp),
            horizontalArrangement = Arrangement.spacedBy(5.dp)
        ) {
            "ASDFGHJKL".forEach { char ->
                KeyButton(
                    label = char.toString(),
                    modifier = Modifier.weight(1f),
                    theme = theme,
                    onClick = { onKeyPress(char) }
                )
            }
        }
        
        // 第三行：⇧ Z X C V B N M ⌫
        Row(
            horizontalArrangement = Arrangement.spacedBy(5.dp)
        ) {
            // Shift 键
            FunctionKey(
                label = "⇧",
                modifier = Modifier.weight(1.2f),
                theme = theme,
                onClick = { /* 切换大小写 */ }
            )
            
            // 字母键
            "ZXCVBNM".forEach { char ->
                KeyButton(
                    label = char.toString(),
                    modifier = Modifier.weight(1f),
                    theme = theme,
                    onClick = { onKeyPress(char) }
                )
            }
            
            // 删除键
            FunctionKey(
                label = "⌫",
                modifier = Modifier.weight(1.2f),
                theme = theme,
                onClick = { /* 删除 */ }
            )
        }
        
        // 第四行：功能键行
        Row(
            horizontalArrangement = Arrangement.spacedBy(5.dp)
        ) {
            // 符号切换
            FunctionKey(label = "符", theme = theme)
            
            // 语言切换
            FunctionKey(label = "中", theme = theme)
            
            // 标点
            FunctionKey(label = "!,", theme = theme)
            
            // 空格键
            SpaceKey(
                modifier = Modifier.weight(1f),
                theme = theme
            )
            
            // 标点
            FunctionKey(label = "?。", theme = theme)
            
            // 搜索
            SearchKey(theme = theme)
        }
    }
}
```

## 8. 触觉反馈

### 8.1 反馈类型

```kotlin
enum class HapticFeedbackType {
    LIGHT,      // 轻触反馈（普通按键）
    MEDIUM,     // 中等反馈（功能键）
    HEAVY,      // 重反馈（删除键）
    SUCCESS,    // 成功反馈（确认操作）
    ERROR       // 错误反馈（错误操作）
}
```

### 8.2 反馈实现

```kotlin
@Composable
fun KeyButton(
    label: String,
    hapticType: HapticFeedbackType = HapticFeedbackType.LIGHT,
    onClick: () -> Unit
) {
    val hapticFeedback = LocalHapticFeedback.current
    
    Box(
        modifier = Modifier
            .pointerInput(Unit) {
                detectTapGestures(
                    onTap = {
                        when (hapticType) {
                            HapticFeedbackType.LIGHT ->
                                hapticFeedback.performHapticFeedback(HapticFeedbackType.TextHandleMove)
                            HapticFeedbackType.MEDIUM ->
                                hapticFeedback.performHapticFeedback(HapticFeedbackType.LongPress)
                            HapticFeedbackType.HEAVY ->
                                hapticFeedback.performHapticFeedback(HapticFeedbackType.LongPress)
                            HapticFeedbackType.SUCCESS ->
                                hapticFeedback.performHapticFeedback(HapticFeedbackType.LongPress)
                            HapticFeedbackType.ERROR ->
                                hapticFeedback.performHapticFeedback(HapticFeedbackType.LongPress)
                        }
                        onClick()
                    }
                )
            }
    ) {
        // 按键内容
    }
}
```

```kotlin
@Composable
fun RippleEffect(
    color: Color,
    modifier: Modifier = Modifier
) {
    var animationState by remember { mutableStateOf(0f) }
    
    LaunchedEffect(Unit) {
        animate(
            initialValue = 0f,
            targetValue = 1f,
            animationSpec = tween(durationMillis = 300)
        ) { value ->
            animationState = value
        }
    }
    
    Box(
        modifier = modifier
            .size(48.dp)
            .drawBehind {
                drawCircle(
                    color = color.copy(alpha = 0.3f * (1 - animationState)),
                    radius = size.minDimension / 2 * animationState
                )
            }
    )
}
```

### 9.3 脉冲动画

```kotlin
@Composable
fun PulseAnimation(
    color: Color,
    modifier: Modifier = Modifier
) {
    val infiniteTransition = rememberInfiniteTransition()
    
    val pulseScale by infiniteTransition.animateFloat(
        initialValue = 1f,
        targetValue = 1.2f,
        animationSpec = infiniteRepeatable(
            animation = tween(1000),
            repeatMode = RepeatMode.Reverse
        )
    )
    
    val pulseAlpha by infiniteTransition.animateFloat(
        initialValue = 0.3f,
        targetValue = 0.1f,
        animationSpec = infiniteRepeatable(
            animation = tween(1000),
            repeatMode = RepeatMode.Reverse
        )
    )
    
    Box(
        modifier = modifier
            .size(48.dp)
            .graphicsLayer {
                scaleX = pulseScale
                scaleY = pulseScale
                alpha = pulseAlpha
            }
            .background(
                color = color,
                shape = CircleShape
            )
    )
}
```

```kotlin
@Composable
fun AccessibleKeyButton(
    label: String,
    isHighContrast: Boolean
) {
    val backgroundColor = if (isHighContrast) {
        Color.White
    } else {
        Color(0xFF1A2332)
    }
    
    val textColor = if (isHighContrast) {
        Color.Black
    } else {
        Color.White
    }
    
    val borderColor = if (isHighContrast) {
        Color.Black
    } else {
        Color(0xFF00D4FF).copy(alpha = 0.3f)
    }
    
    Box(
        modifier = Modifier
            .background(
                color = backgroundColor,
                shape = RoundedCornerShape(16.dp)
            )
            .border(
                width = if (isHighContrast) 3.dp else 1.dp,
                color = borderColor,
                shape = RoundedCornerShape(16.dp)
            )
    ) {
        Text(
            text = label,
            color = textColor,
            fontSize = if (isHighContrast) 24.sp else 20.sp,
            fontWeight = if (isHighContrast) FontWeight.Bold else FontWeight.SemiBold
        )
    }
}
```
